# US-057: Utilidad CLI de Archivos CSV

Como data analyst,
Quiero una utilidad CLI para manipular archivos CSV
Para automatizar tareas de procesamiento de datos

## Criterios de Aceptación

- `csvtool convert <input.csv> <output.json>` — Convertir CSV a JSON
- `csvtool filter <input.csv> <column> <value>` — Filtrar filas por valor de columna
- `csvtool merge <file1.csv> <file2.csv>` — Combinar dos archivos CSV
- `csvtool stats <input.csv>` — Mostrar estadísticas del archivo
- Validación de archivos existentes con mensajes de error claros
- Help message completo con ejemplos de uso
- Salida con código de error correcto (0 = OK, 1 = error)

## Notas Técnicas

- Stack: Python stdlib únicamente (csv, json, argparse, pathlib, statistics)
- Arquitectura: CLI + Commands + Models + Utils (modular)
- Tests: pytest + pytest-bdd
- Sin dependencias externas (solo herramientas de testing)
- Python 3.10+
