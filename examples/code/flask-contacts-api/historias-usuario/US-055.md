# US-055: API REST de Contactos con Flask

## Historia de Usuario

**Como** desarrollador frontend
**Quiero** una API REST para gestionar contactos
**Para** construir una aplicación de agenda de contactos

## Criterios de Aceptación

### CA-1: Listar Contactos
- [x] GET /contacts debe retornar lista de contactos en formato JSON
- [x] Status code 200 OK
- [x] Respuesta debe ser un array de contactos

### CA-2: Obtener Contacto por ID
- [x] GET /contacts/{id} debe retornar el contacto con ese ID
- [x] Status code 200 OK si existe
- [x] Status code 404 Not Found si no existe

### CA-3: Crear Contacto
- [x] POST /contacts debe crear un nuevo contacto
- [x] Campos requeridos: nombre, email, teléfono
- [x] Status code 201 Created
- [x] Retornar el contacto creado con ID asignado

### CA-4: Actualizar Contacto
- [x] PUT /contacts/{id} debe actualizar el contacto
- [x] Status code 200 OK si existe y se actualiza
- [x] Status code 404 Not Found si no existe
- [x] Retornar el contacto actualizado

### CA-5: Eliminar Contacto
- [x] DELETE /contacts/{id} debe eliminar el contacto
- [x] Status code 204 No Content si se elimina
- [x] Status code 404 Not Found si no existe

### CA-6: Validación de Email
- [x] Email debe tener formato válido (contiene @)
- [x] Status code 400 Bad Request si email inválido
- [x] Mensaje de error descriptivo

### CA-7: Manejo de Errores
- [x] 404 si contacto no existe
- [x] 400 si datos inválidos
- [x] Mensajes de error en formato JSON

## Notas Técnicas

- Arquitectura: Flask + Blueprint + Services Layer
- Base de datos: In-memory (dict) para simplicidad
- Testing: pytest + pytest-bdd + Flask test_client
- Quality Gates: pylint >= 8.5, coverage >= 95%
