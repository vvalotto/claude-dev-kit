# US-056: Aplicación de Blog con Flask

## Historia de Usuario

**Como** usuario
**Quiero** una aplicación web de blog
**Para** publicar y leer artículos

## Criterios de Aceptación

- ✅ Ver lista de posts en la página principal (con paginación)
- ✅ Ver detalle de un post
- ✅ Crear nuevo post (formulario web)
- ✅ Editar post existente (formulario web)
- ✅ Eliminar post (con confirmación)
- ✅ Formularios con validación (título requerido, contenido mínimo)
- ✅ Interfaz web con HTML/CSS (no API REST)
- ✅ Session flash messages (éxito/error)

## Contexto Técnico

- **Framework**: Flask WebApp (FULLSTACK)
- **Perfil**: flask-webapp
- **Base de datos**: In-memory storage (para ejemplo)
- **Templates**: Jinja2
- **Forms**: Flask-WTF
- **Validación**: WTForms validators
- **CSS**: Static files básicos

## Arquitectura

```
flask-blog-app/
├── app/
│   ├── __init__.py (application factory)
│   ├── models/
│   │   └── post.py (Post dataclass)
│   ├── database.py (in-memory storage)
│   ├── forms/
│   │   └── post_form.py (WTForms)
│   ├── routes/
│   │   └── blog.py (Flask Blueprint)
│   ├── templates/
│   │   ├── base.html
│   │   ├── index.html
│   │   ├── post_detail.html
│   │   ├── post_form.html
│   │   └── confirm_delete.html
│   └── static/
│       └── style.css
└── main.py
```

## Endpoints (retornan HTML)

- `GET /` - Lista de posts
- `GET /post/<id>` - Detalle de post
- `GET /post/new` - Formulario de crear
- `POST /post/new` - Procesar creación
- `GET /post/<id>/edit` - Formulario de editar
- `POST /post/<id>/edit` - Procesar edición
- `GET /post/<id>/delete` - Confirmación
- `POST /post/<id>/delete` - Procesar eliminación

## Notas

Este es un ejemplo FULLSTACK de Flask WebApp, no una API REST. Los endpoints retornan HTML usando templates Jinja2.
