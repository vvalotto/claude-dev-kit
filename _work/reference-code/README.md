# Código de Referencia

## ⚠️ Importante

El código aquí **NO fue generado usando el framework Claude Dev Kit**. Fue escrito directamente para servir como referencia de cómo debería verse el código final.

- **Referencia de estructura:** Muestra cómo debería organizarse el código siguiendo los patrones del framework

- **Comparación:** Útil para comparar con código generado por el framework
